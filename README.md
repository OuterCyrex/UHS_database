# UHS 科研数据库

## 项目简介

UHS 科研数据库是一个面向地下储氢（Underground Hydrogen Storage, UHS）领域的开放科研数据平台。它旨在系统收录、规范整理并公开发布与 UHS 相关的一手实验测量数据，让分散在不同实验室、不同文献中的测量结果能够被统一检索、交叉比较和正式引用。

地下储氢被视为大规模氢经济的关键支撑技术之一，但该领域目前面临一个基础性问题：**实验数据极度稀缺且高度分散**。接触角、界面张力、渗透率、孔隙度等关键参数，往往只在一两篇论文中被报道过，测量方法不统一，数据质量参差不齐，后来者很难判断哪些数据可信、哪些条件可复用。现有公开数据集多为文献汇编或合成数据，缺少由研究者主动贡献的一手测量数据。

本项目正是针对这一空白而设计。我们的长期目标是成为 UHS 领域可被全球研究者使用和引用的数据基础设施；近期目标则是先跑通一个最小可用的原型，验证数据模型和协作流程是否合理。

## 我们要解决什么问题

当前 UHS 领域的数据状况可以概括为三个字：**少、散、难**。

- **少**：许多关键参数在整个文献中只有单一研究报道。例如 H₂-水-砂岩体系的毛管压力和相对渗透率曲线，目前公开数据仅来自一项研究。
- **散**：数据散落在不同期刊、不同图表、不同补充材料中，没有统一入口，检索成本极高。
- **难**：同一物性用不同方法测出的值可能相差一倍以上。H₂-H₂O 界面张力直接测量约为 72 mN/m，而用压汞数据拟合估算仅 51 mN/m，后者已被原作者明确质疑可靠性。如果不记录测量方法，这些数据混在一起就无法使用。

本项目通过建立结构化的数据模型、强制的元数据规范和可引用的发布机制，让每一条数据都能回答三个问题：**谁测的、怎么测的、在什么条件下测的**。

## 近期目标

近期（约 6 个月）聚焦于做出一个**可演示、可讨论、可迭代的原型**，而不是一个功能完整的平台。具体目标按优先级排列：

**第一，建立第一版数据模型。** 确定数据库需要哪些表、每张表有哪些字段、哪些字段必填、单位如何统一。原型阶段优先覆盖三类核心数据：接触角、界面张力、渗透率与孔隙度。数据模型会以 Excel 模板和 SQLite 建表脚本两种形式呈现，方便导师直接审阅和修改。

**第二，用真实数据验证模型。** 从已发表文献中手动摘录 10–20 条真实测量数据，按模板录入，检验字段是否够用、规范是否可执行。这一步的目的是暴露问题，而不是追求数据量。

**第三，跑通“录入—审核—发布—引用”的完整流程。** 数据先以 Excel 提交、人工审核的方式入库，随后将数据包上传至 Zenodo，申请 DOI，验证数据可被正式引用的机制。这一步会同时确定许可证（拟采用 CC BY 4.0）和贡献者标识（ORCID）的使用方式。

**第四，做出最简查询界面。** 一个单页表格，支持按矿物类型、温度范围、压力范围筛选，支持导出 CSV。不做用户登录、不做在线上传、不做复杂可视化——这些留到数据模型被确认之后再迭代。

## 不在近期范围内的事

为了避免范围蔓延，以下内容明确不在原型阶段处理：用户注册与权限系统、在线上传表单、复杂数据可视化、实时协作编辑、与外部数据库的自动同步。这些功能是否要做、什么时候做，取决于原型验证的结果和导师的判断。

## 项目原则

**方法必须可追溯。** 任何测量数据都必须记录测量方法，且方法字段不得为空。这是数据能否被复用的前提。

**来源必须可引用。** 每条数据都要关联到原始文献的 DOI；数据集本身在发布时也要获得 DOI，让贡献者的工作可被正式引用。

**规范先于代码。** 数据模型和录入规范确定之前，不急于开发界面和功能。原型阶段最大的风险不是技术实现，而是数据模型设计错误导致返工。

**简单优先。** 技术选型以“换人接手成本低”为标准。SQLite 起步，前端只做必要功能，原始文件托管在 Zenodo 而非自建存储。

## 当前状态

项目处于起步阶段。已完成的工作包括：UHS 领域关键参数的文献梳理、现有公开数据集的调研（HyDRA 欧洲多孔储层数据库、SUHS-MRV 合成数据集、Digital Porous Media Portal 等）、第一版数据模型的初步设计。下一步是与导师确认数据模型和字段规范，然后进入真实数据录入验证。

## 参考与对标

- Digital Porous Media Portal：多孔介质图像与实验测量数据库，按项目组织、发 DOI，与本项目数据形态最接近
- NOMAD：材料科学领域同时收录计算与实验数据的开放仓库，其元数据 schema 设计值得参考
- HyDRA：欧洲 UHS 多孔储层站点数据库，托管于 Zenodo，有 DOI
- re3data：全球研究数据仓库注册库，可用于检索各领域数据库的字段组织和治理模式 (https://www.re3data.org/)
