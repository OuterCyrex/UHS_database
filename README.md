# UHS Research Data Prototype

一个面向地下储氢（Underground Hydrogen Storage, UHS）孔隙尺度研究的前端原型。当前重点是展示接触角实验数据，并验证按固体样品、流体体系和实验条件组合查询的交互流程。项目目前是静态数据驱动的 Vue 应用，不包含后端服务或正式数据库。

## 当前功能

- 首页：介绍 UHS 孔隙尺度研究背景，并根据本地数据文件展示记录概况。
- 搜索入口：按固体性质、流体性质、固-流体相互作用选择目标结果。
- 条件筛选：三类筛选条件可独立折叠，支持单位选择、结果表格、分页和接触角详情。
- 语言：支持简体中文和英文，默认英文。页面标签页标题为英文。

当前只有“润湿性 / 接触角”目标有对应结果。筛选页里其他结果参数目前没有数据；对应页面会提示暂无结果。

## 当前数据

数据文件：`data/contact-angle-data.json`。原始来源记录为 `[New] CA data collection.xlsx`。数据是构建时导入的本地 JSON，不是运行时连接的数据库。

JSON 元数据标注 263 条记录，字段包括：

| 类别 | 字段 | 单位 |
| --- | --- | --- |
| 来源 | `reference` | — |
| 样品 | TOC、石英、方解石、白云石、黏土、长石 | wt% |
| 流体 | 盐水离子强度、油相含量 | mol/L、原表数值 |
| 实验条件 | 温度、压力 | °C、MPa |
| 结果 | 前进接触角、后退接触角 | ° |

当前筛选页实际对下列数据字段执行精确值匹配：矿物组成、TOC、盐水离子强度、油相含量、温度、压力。温度 K 和压力 bar 会换算到源数据单位。其余筛选项目前只是界面字段，不会参与当前数据匹配；单位无法换算的选项也会显示提示。

### 数据质量与发布注意事项

- JSON 的 `record_count` 为 263，但数据行中存在一条 `reference` 值为 `experiment` 的疑似表头记录；需要回到 Excel 核对并清理后再用于统计或正式发布。
- 首页文献来源数按 `reference` 去重统计，因此目前会把 `experiment` 也计作一个来源；该数字在清理这条记录前不应视为有效文献数。
- `oil` 字段在 JSON 的 `units` 元数据中没有单位定义，界面目前按 wt% 展示；发布前应核对源表单位。
- `reference` 当前是表内编号，不是完整文献引文或 DOI。
- `.gitignore` 忽略了整个 `data/` 目录，而应用在构建时直接导入 JSON。新环境或部署环境必须另行提供该文件；若希望数据随项目版本管理，需要先确定数据许可与仓库策略，再调整忽略规则。

## 技术栈

- Vue 3、TypeScript、Vite
- Vue Router、Pinia、Vue I18n
- Tailwind CSS 4、Element Plus

## 本地运行

需要 Node.js 和 npm。确认 `data/contact-angle-data.json` 存在后运行：

```sh
npm install
npm run dev
```

常用检查：

```sh
npm run type-check
npm run build-only
```

## 页面路由

| 路径 | 页面 |
| --- | --- |
| `/` | 首页 |
| `/search` | 目标结果选择 |
| `/search/conditions` | 组合条件筛选与查询结果 |

## 尚未实现

当前没有关系型数据库、后端 API、在线数据录入 / 审核、CSV 导出、用户权限或 DOI 发布流程。绝对渗透率、有效孔隙度、密度、黏度、界面张力、溶解度、扩散系数、毛细压力、相对渗透率等结果类型仍是查询入口，不代表已有相应数据。

后续扩展应避免把不同结果类型强行放入同一组结果列。建议以实验 / 样品 / 流体 / 实验条件为上下文，将测量结果建模为带有参数类型、数值、单位、方法和来源的独立记录；详情展示再依据结果类型呈现专属字段。该数据模型尚未在本项目中实现。
